# Solarized Light 主题 
    Auto Rename Tag自动重命名配对的 HTML / XML 标签
    
# Bracket Pair Colorizer
    颜色标识匹配的括号，用户可以定义要匹配的符号，以及要使用的颜色。
    
# ColorHighlight
    程序设置在文档中找到的 css / web 颜色的样式。
    
# CSS PeekPeek
    内联加载、css 文件并在那里进行快速编辑。（Ctrl + Shift + F12）
    Go to：直接跳转到 CSS文件或在新的编辑器（F12）中打开 
    Hover：在符号上悬停显示定义（Ctrl + hover）
    
# DotENV

# Highlight Matching Tag
    突出显示匹配的开始或结束标签。 
    
# Imagepreview
    悬停时显示图像预览。 
    
# TODO Highlight
    在代码中突出显示 TODO，FIXME和其他注释
    
# Version Lens
